# LIAN CONNECT v0.03（测试版）

- 应用版本：`0.0.3`（`versionCode` `3`）
- 包名：`com.lianconnect.app`
- 架构：arm64
- 发布 HAP：脱敏、未签名；需使用自己的证书和 Profile 签名后安装。

## 本次更新

- 面向 8 GB 与 12 GB 内存档位的 HarmonyOS 设备做低内存适配。释放 GeoSite 原始加载数据并请求 Go 释放可回收内存，同时保留编译后的规则 matcher；每个 DNS resolver 的缓存上限为 1024。
- 保留 VPN 状态心跳和命令响应，依据连接页、其他前台页面和后台状态调整连接明细快照频率，减少后台轮询与序列化开销。
- 移除生产界面的演示状态和错误的核心名称。连通性检查与节点测速使用 mihomo 代理 URLTest。
- DNS 模式、缓存、Fake-IP、嗅探、网络自动恢复、断线阻断及日志级别接入实际运行配置；诊断页支持复制、导出和清空。
- 扩充分应用代理应用目录，修正显示名，增加置顶添加、批量包名导入与手动录入，并处理重复包名。
- 增加内存回归、已知问题回归和设备资源采样脚本。

## 验证状态

- 本地记录：AArch64 mihomo 核心与 HAP 构建成功，ArkTS 类型检查及内存、已知问题、稳定性和发布预检通过。
- 当前设备上的短时连接和内存检查通过；本机记录的系统总内存约 16 GB。
- 本版本的 8 GB/12 GB 设备长时间锁屏、后台内存趋势和网络切换验收仍待完成。因此“面向 8 GB/12 GB 优化”描述的是代码适配目标，不代表已在两个档位完成长期验收。

## 安装

GitHub Release 附带的 HAP 未签名且不包含个人证书或 Profile。请按
[自签与安装说明](SELF_SIGNING.md) 使用自己的 HarmonyOS 签名材料签名，再安装到设备。
